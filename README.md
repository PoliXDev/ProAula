# ProAula

Sistema web de gestión académica para un colegio: panel del personal y portal familiar.

El personal del colegio trabaja en un panel hecho con Django (aulas, matrícula, notas, asistencia, comunicados y mensualidades). Las familias entran por un portal en React y solo ven la información de sus hijos.

## Tecnologías

- Python y Django (panel del personal)
- API propia con Django REST Framework (datos del portal)
- React, Vite y Tailwind CSS (portal familiar)
- SQLite en desarrollo local
